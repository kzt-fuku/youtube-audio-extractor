# OtoClip v1.0.0

YouTube のリンクを貼り付けるだけで MP3 を取得するアプリです。
PC で起動すると、PC のブラウザからも、同じ Wi-Fi につないだスマホ（iPhone / Android）からも使えます。

## 仕組み

```
[スマホのブラウザ] ──Wi-Fi──┐
                            ├─> [PC: OtoClip サーバー] ─> yt-dlp ─> ffmpeg ─> MP3
[PC のブラウザ] ────────────┘                                        └─ 保存先フォルダ
```

- 変換は PC 側で行います。スマホは操作画面と保存だけを担当するため、スマホに追加アプリは不要です。
- ffmpeg と JavaScript ランタイム (deno) は pip で自動導入されるため、手動インストールは不要です。

## 使い方

### 1. 準備（初回のみ）

1. Python 3.10 以上をインストールします（https://www.python.org/downloads/ ）。
   - Windows: インストール画面で「Add python.exe to PATH」にチェックを入れてください。
   - macOS: python.org のインストーラーか Homebrew (`brew install python`) で入れてください。
2. このフォルダ（`youtube-audio-extractor`）を PC の好きな場所に置きます。

### 2. 起動

| OS | 操作 |
|---|---|
| Windows | `start_windows.bat` をダブルクリック |
| macOS | `start_mac.command` をダブルクリック |
| Linux | `bash start.sh` を実行 |

初回は必要なライブラリを自動で入れるため 1～3 分かかります。起動するとブラウザで `http://localhost:8765/` が開きます。
2 回目以降は数秒で起動します。環境が壊れていても自動で作り直すので、フォルダを移動・改名しても問題ありません。

macOS で「開発元を確認できないため開けません」と出る場合は、右クリック→「開く」、
または「システム設定」→「プライバシーとセキュリティ」の「このまま開く」で許可してください（初回のみ）。

### 3. MP3 を取得

1. YouTube のリンクをコピーします。
2. 入力欄に貼り付けます（「貼り付け」ボタンでも可）。貼り付けただけでは始まりません。
3. Enter キーを押すか「MP3 を取得」を押すと取得が始まります。
4. 完了したら「保存」でダウンロード、「再生」でその場で試聴できます。

MP3 は PC の `ミュージック/OtoClip` フォルダにも保存されます（「フォルダを開く」で表示）。
タイトル・投稿者名・サムネイル画像が MP3 に埋め込まれます。

### 4. スマホで使う

1. スマホを PC と同じ Wi-Fi につなぎます。
2. PC の画面下部の QR コードをスマホのカメラで読み取ります。
3. 開いたページを「ホーム画面に追加」すると、アプリのように起動できます。
   - iPhone: Safari の共有ボタン → 「ホーム画面に追加」
   - Android: Chrome のメニュー → 「ホーム画面に追加」
4. スマホで「保存」を押すと、iPhone は「ファイル」アプリ、Android は「ダウンロード」フォルダに保存されます。

## 注意点

- **PC を起動しておく必要があります。** スマホだけでは動きません（変換処理を PC が担当するため）。
- **Windows のファイアウォール**: 初回起動時に「アクセスを許可しますか」と出たら「プライベート ネットワーク」を許可してください。許可しないとスマホから接続できません。
- **スマホから開けない場合**: PC とスマホが同じ Wi-Fi か確認してください。学校・公共 Wi-Fi は端末間通信が禁止されていることが多く、その場合はスマホのテザリングに PC をつなぐと使えます。
- **合言葉 (QR コード内の `t=...`)**: 同じ Wi-Fi の他人が勝手に使えないよう、PC 以外からのアクセスには合言葉が必要です。漏れた場合は `.otoclip/config.json` の `token` を削除して再起動すると新しくなります。
- **取得に失敗する場合**: YouTube 側の仕様変更が原因のことが多いです。起動スクリプトは毎回 yt-dlp の更新を確認するので、再起動で直る場合があります。
- **権利について**: 自分が権利を持つ動画や、作者がダウンロードを許可している動画（クリエイティブ・コモンズ等）に限って使ってください。YouTube の利用規約では、許可のないダウンロードは禁止されています。

## 設定

`.otoclip/config.json`（初回起動時に自動作成）を編集すると変更できます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| `download_dir` | MP3 の保存先 | `~/Music/OtoClip` |
| `port` | 使用するポート番号 | `8765` |
| `token` | スマホ接続用の合言葉 | 自動生成 |

環境変数 `OTOCLIP_DIR` / `OTOCLIP_PORT` でも一時的に上書きできます。

## ファイル構成

```
otoclip/
  __main__.py     起動処理（ブラウザを開く、接続先 URL を表示）
  server.py       Web サーバー（API、合言葉による認証、ファイル配信）
  downloader.py   yt-dlp による取得・MP3 変換・進み具合の管理
  static/         画面（HTML / CSS / JS、ホーム画面追加用の manifest とアイコン）
start.py          共通の起動処理（.venv 作成、ライブラリ導入、yt-dlp 更新、アプリ起動）
start_windows.bat / start_mac.command / start.sh   OS ごとの入口（Python を探して start.py を呼ぶ）
requirements.txt  依存ライブラリ
```
